为什么不直接减掉饮料的标价？

不想喝饮料，并不意味着结账会少付这笔钱。我们比较整单实际付款，并列明附带食物。含饮料的套餐如果实付更低，也会在允许饮料时参与比较；本例碰巧是单点更便宜。

严格不要饮料时，含饮料套餐退出推荐。没有查到可以取消或替换的官方结果，就不假设可以免费换成别的餐品。
