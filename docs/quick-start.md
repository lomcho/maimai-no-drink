# 使用麦麦不喝饮料星人

## 先看效果：不用安装

**[打开在线体验](https://lomcho.github.io/maimai-no-drink/)**。GitHub 文件链接仅展示源码；此链接直接打开网页。

打开同目录的 index.html，选择麦辣/板烧以及能否接受套餐饮料，比较总价和额外食物，复制带日期说明的结果。页面使用历史真实快照，不请求账号、不查实时价格、不下单。下载仓库 ZIP 后，解压并双击 docs/index.html 即可使用；无需启动服务器。

## 我们自己的 Codex：直接说需求

技能安装好后，新建一个 Codex 对话，输入：

> 使用 $maimai-no-drink。我想吃一个麦辣鸡腿堡、一对鸡翅，家里有饮料。按麦乐送实付比较，沿用我确认过的配送地址，不下单。

如果新对话不知道此前地址，会请你选择一次，不会猜测。已有饮料并不强制排除套餐；希望套餐也不能带饮料，请说“完全不要饮料”。

## 首次安装（Codex / Windows）

1. 在仓库页面点击 Code → Download ZIP，解压到自己能找到的文件夹。
2. 打开麦当劳官方平台 https://open.mcd.cn/mcp ，登录并开通自己的 Token。不要把 Token 发到聊天、截图或 GitHub。
3. 在 Codex 的 MCP 设置中添加名为 mcd-mcp 的连接，选择流式 HTTP，地址 https://mcp.mcd.cn。使用客户端提供的私有认证设置，按官方指南填写 Bearer 认证。没有环境变量时，不要把实际 Token 填进“环境变量名称”栏。已有连接不必重复添加。
4. 将解压目录里的 skills/maimai-no-drink 整个文件夹复制到 %USERPROFILE%/.codex/skills/ 。目标应直接包含 SKILL.md 和 scripts、references 子目录。已有同名技能时先备份旧文件夹。
5. 新建对话，发送上面的示例。只需要配置一次；每次询价仍需要联网。

## 原生工具未出现时

本项目带有 scripts/mcp_readonly.py 只读备用入口（在技能目录内）。它优先使用本机 MCD_MCP_TOKEN 环境变量，否则通过 codex mcp get mcd-mcp --json 读取该连接的私有认证。需要 Python 3.10+，使用 Codex 配置回退时还需要 codex 命令可用。认证仅发送至固定官方端点，拒绝重定向，不打印或保存凭证。

助手先运行 python <技能目录>/scripts/mcp_readonly.py list 读取实时参数，再准备合法只读请求。用户不需要手工拼参数。普通查询结果可能包含个人信息，助手应只展示必要字段，不能把完整响应粘贴到公开问题里。

只允许查地址、门店、菜单、详情、券和价格，不提供下单、改地址、领券、购买会员接口。遇到连接失败/401/403/429，停止并说明原因；不要用体验页价格冒充实时结果。

其他客户端：支持远程 MCP 且能读取技能说明时，可导入完整技能文件夹。备用入口需要本机 Python 和 MCD_MCP_TOKEN；不承诺所有客户端都已测试。

## 常见问题

- 页面里复制失败：下方保留完整文本，可长按或全选复制。
- 真实询价很贵：这里只比较本次官方麦乐送候选，不覆盖第三方外卖平台或全菜单最低价。
- 报价是不是一直有效：不是。购买前重新核价。
- 我需要改名成英文吗：仓库标识 maimai-no-drink 已是英文；产品名称保留中文。官方排行榜当前展示的项目名称与仓库名对应，参赛 Issue 保留中文无需为此重报。
