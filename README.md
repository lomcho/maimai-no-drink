# 麦麦不喝饮料星人

## 👉 [点击这里：在线多选体验](https://lomcho.github.io/maimai-no-drink/)

上面是可直接使用的网页入口。GitHub 文件列表用于查看代码，网页不会嵌入文件列表。


**家里有喝的，只想吃一个堡、一对翅——让 AI 查清楚实际要付多少钱。**

面向已有饮料、希望按需点餐的麦乐送用户的免费 Skill。接受任意餐品需求，以当前门店完整菜单与套餐子项为依据，默认只推荐不含饮料、满足指定份量的方案。通过官方 MCP 查询实时菜单、套餐详情、个人可用券和价格，比较含配送打包费的实际付款。

## 安装与使用

1. 在 https://open.mcd.cn/mcp 开通本人 Token。
2. 在支持 MCP 的助手里连接 https://mcp.mcd.cn，使用本地凭证。mcp-config.example.json 仅含环境变量占位符，插值方式取决于客户端，不能直接视为已认证配置。
3. 将 skills/maimai-no-drink 放入助手技能目录。Codex 可放入 ~/.codex/skills/maimai-no-drink，然后重新加载。
4. 输入：“我想吃一个鸡腿堡、一对鸡翅，家里有饮料，怎么买划算？”也可明确调用 $maimai-no-drink。

已说明的需求沿用；不明确的口味可以先并列报价，不要求先填长问卷。

|用户说法|处理|
|---|---|
|家里有饮料或可乐|默认只比较不含饮料的方案；仅明确允许时扩展含饮料套餐|
|套餐也别带饮料|排除不可取消的饮料|
|不喝可乐，想喝咖啡|保留咖啡需求，不误判成所有饮料都不要|

## v0.5：按需买与加量备选

实时 Skill 默认同时查找两类无饮料方案：精确需求的最低实付，以及包含全部目标餐品、额外增加食物的套餐组合。备选明确展示整单差价和多出的食物，最多两项；默认仅展示加价不超过5元的选项，用户可指定上限或说“只要这些”关闭。更便宜的加量组合也会单列；没有基准不虚构差价。加价不称作省钱，结果仅限本次已核验的候选。

Skill 与在线体验均已提供按需买及加量备选。在线页支持5/10/20元加价上限，沿用历史核价数据；本轮交互回归不代表新增实时套餐已经查询。
